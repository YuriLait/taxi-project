# Taxi Bonus — полный пакет

В архиве три направления сразу:

## 1) `local_v3`
Готовая локальная версия, которую можно открыть прямо двойным кликом.
Подходит для демонстрации, ручной работы и дальнейшей доработки.

## 2) `backend_supabase_blueprint`
Заготовка серверной части и схемы БД.
Подходит как следующий шаг после `localStorage`.

## 3) `react_blueprint`
Стартовая структура фронтенда на React/Vite.
Подходит для перехода на поддерживаемую архитектуру.

## Что уже улучшено в local_v3
- фильтр по датам
- автоподстановка клиента по телефону
- последние маршруты клиента
- автоназначение первого свободного водителя
- индикатор ожидания по заказам
- звуковое уведомление при новом заказе
- сводка смены за день
- расширенный отчёт по водителям и оплатам

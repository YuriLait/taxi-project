Как подготовить оффлайн OpenStreetMap для всей России

В архив добавлена поддержка локальной OSM-карты, но не вся карта РФ: полный набор тайлов слишком большой для обычного архива сайта.

Статический вариант:
  local_v3/assets/osm/tiles/{z}/{x}/{y}.png

Продакшн-вариант:
  Russia .osm.pbf / .mbtiles + локальный TileServer GL / OSRM.
